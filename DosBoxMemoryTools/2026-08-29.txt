Notiz für morgen – MM3 Tastatur-Button-Modus
Stand: 30.08.2026

ZIEL

Might and Magic III soll im GridBuilder vollständig per Tastatur bedienbar sein, auch wenn DOSBox nicht den Fokus hat.

Normale Bewegung:
- Pfeil hoch = vorwärts
- Pfeil runter = rückwärts
- Pfeil links = links drehen
- Pfeil rechts = rechts drehen

Button-Modus:
- End schaltet Button-Modus ein/aus.
- Im Button-Modus wird die normale Bewegung blockiert.
- Pfeiltasten sollen grafische MM3-Buttons auswählen.
- Return soll den ausgewählten Button aktivieren.
- Bedienung ohne physische Maus.


AKTUELLER FUNKTIONIERENDER STAND

- MM3GameModule erhält Tastatureingaben unabhängig vom DOSBox-Fokus.

- Die normalen Pfeiltasten bewegen MM3 auch dann, wenn die Maus über anderen GridBuilder-Fenstern steht.

- End schaltet m_buttonMode zuverlässig ON/OFF.

Debug-Ausgabe:
MM3 Button Mode: ON
MM3 Button Mode: OFF

- MM3GameModule::blockDirectDosBoxKeyboard() liefert m_buttonMode zurück.

- EditorApplication reicht diesen Zustand an DosBoxWindow weiter.

- DosBoxWindow besitzt:
  m_directKeyboardBlocked

- m_keyboard.update() läuft nur bei:

  m_inputActive &&
  !m_directKeyboardBlocked

- Dadurch bewegt sich die Party im Button-Modus nicht mehr.

- Escape wird über:

  m_pendingDosKey = "ESC";

  an DOSBox geschickt.

- takeDosKey() transportiert MM3-DOS-Tasten über EditorApplication zu:

  DosBoxWindow::sendDosKey()


BUTTON-AUSWAHL

MM3GameModule besitzt:

bool m_buttonMode;
int m_selectedButton = -1;

Beim Einschalten mit End:

m_buttonMode = true;
m_selectedButton = 0;

Beim Ausschalten:

m_selectedButton = -1;

Im Button-Modus:

Pfeil hoch:
m_selectedButton = 0;

Pfeil runter:
m_selectedButton = 1;

Die normale Party-Bewegung wird dabei nicht ausgeführt.


GAME MODULE SCHNITTSTELLE

GameModule besitzt die neutrale Schnittstelle:

gameButtonSelection(
    int& selectedButton
) const

MM3GameModule überschreibt diese und gibt im Button-Modus den aktuellen selectedButton zurück.


DOSBOX WINDOW

DosBoxWindow besitzt:

setGameButtonSelection(
    bool active,
    int selectedButton
);

sowie:

bool m_gameButtonSelectionActive;
int m_selectedGameButton;

EditorApplication verbindet:

GameModule::gameButtonSelection()

mit:

DosBoxWindow::setGameButtonSelection()


GRAFISCHE HERVORHEBUNG

Direkt vor ImGui::Image() wird gespeichert:

const ImVec2 imagePos =
    ImGui::GetCursorScreenPos();

Nach ImGui::Image() wird aktuell mit AddRect() ein gelber Auswahlrahmen über das DOSBox-Bild gezeichnet.

Der Rahmen funktioniert und ist sichtbar.

ABER:

Die aktuellen Button-Koordinaten sind nur Platzhalter.

Das gelbe längliche Rechteck erscheint momentan mitten im DOSBox-Bild und sitzt noch NICHT auf den echten MM3-Buttons.

Aktuelle provisorische Werte:

buttonX = 78
buttonWidth = 164
buttonHeight = 24

Button 0:
buttonY = 112

Button 1:
buttonY = 143

Die Position wird mit imagePos und scale auf die dargestellte DOSBox-Größe skaliert.
