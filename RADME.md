# MyImGui

MyImGui is a small C++ static library containing reusable helpers and UI components for Dear ImGui.

## Components

- `FloatingWindow`
- `FlowLayout`
- `DragDropReorder`

## Requirements

- C++20
- Visual Studio
- Dear ImGui

## Projects

- `ImGui` – Dear ImGui static library
- `MyImGui` – reusable UI components
- `MyImGuiTest` – small build and linking test

## Building

1. Open `MyImGui.slnx` in Visual Studio.
2. Select the `x64` platform.
3. Choose **Build → Build Solution**.
