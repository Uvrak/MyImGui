================================================

Aktueller Stand
---------------

Das neue dockbare Fenster:

    Trace Navigation

wird zur zentralen Bedienung für die Execution-Trace-Analyse ausgebaut.

Aktuelles geplantes Layout:

    Instruction [DIV DI ▼] [Search Start]
    Register    [DI     ▼] [Previous]

Später darüber zusätzlich:

    Target [0x31C33] [Record] [Save] [Load]


Navigation
----------

Register-Navigation funktioniert:

    Register [AX/BX/CX/DX/SI/DI/BP/SP/DS/ES/SS]
    Previous

"Previous" sucht rückwärts nach der vorherigen Änderung des
ausgewählten Registers.

Wenn keine weitere Änderung gefunden wird, bleibt die aktuelle
Trace-Position erhalten.

Die ausgewählte Trace-Zeile wird im Execution Trace automatisch
angesprungen und sichtbar gescrollt.


Instruction-Navigation
----------------------

Die Instruction-ComboBox enthält momentan:

    DIV DI
    MOV DI, imm
    MOV BX, AX
    SHL BX, 1
    JMP CS:[BX+...]

WICHTIG:

Es wird KEIN zusätzlicher Instruction-"Previous"-Button benötigt.

Die Bedienung soll sein:

    Search Start
        -> sucht die ausgewählte Instruktion im Trace
        -> springt zum gefundenen Trace-Eintrag

Danach:

    Register auswählen
    Previous
        -> verfolgt die Registeränderungen rückwärts

Der zwischenzeitlich eingeführte separate
m_instructionSearchIndex ist für dieses Bedienkonzept nicht nötig.


Search Start – implementiert / begonnen
---------------------------------------

DIV DI:

    ZYDIS_MNEMONIC_DIV
    Operand 0 = Register DI

MOV DI, imm:

    ZYDIS_MNEMONIC_MOV
    Operand 0 = Register DI
    Operand 1 = Immediate

MOV BX, AX:

    ZYDIS_MNEMONIC_MOV
    Operand 0 = Register BX
    Operand 1 = Register AX
