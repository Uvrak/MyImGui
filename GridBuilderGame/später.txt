MM3ReverseEngineering:

Main Menu:
- Main Menu wird zuverlässig per Pixel-Signatur erkannt.

- Vor dem Main Menu erscheint kein Auswahlrahmen mehr.

- Gelber Auswahlrahmen funktioniert wieder.

- RETURN aktiviert den ausgewählten Button per Mausklick.
- Wechsel vom Main Menu zum Load-Game-Screen funktioniert.

WICHTIGE ARCHITEKTUR

Der sichtbare Bildschirm entscheidet über m_activeWindow.

Nicht mehr:
    "Button X wurde gedrückt, also muss jetzt Fenster Y aktiv sein."

Sondern:
    mainMenuVisible() -> Window 0
    loadGameVisible() -> Window 1
    nichts erkannt -> Window -1

Damit ist die Steuerung unabhängig davon, wie oft vorher ESC/RETURN
gedrückt wurde.
